# 本地文件浏览器 for 思源笔记

在Dock面板快速浏览本地文件，便捷插入本地文件链接为思源附件。

## 功能特点

- **浏览本地驱动器**：使用原生文件系统访问，浏览本地挂载的驱动器
- **一键插入**：双击文件即可自动将其本地链接插入到思源笔记里作为附件，右键菜单复制到 `workspace/data/assets/` 并插入到当前笔记
- **图片支持**：图片使用 `![]()` Markdown 语法直接内联显示
- **文件支持**：其他文件以 `[文件名](assets/...)` 链接形式插入
- **防重复**：文件名自动添加时间戳，避免覆盖已有文件
- **暗色模式**：样式自动适配思源主题
- **多盘符切换**：通过下拉框在多个挂载盘之间切换
- **收藏文件夹**：收藏常用文件夹，快速直达
- **搜索与深度搜索**：实时过滤当前目录，或递归搜索子目录
- **排序功能**：按名称/大小/修改时间排序，支持升序/降序
- **列表与图标视图**：列表模式紧凑显示，图标模式缩略图网格
- **图片悬停预览**：鼠标悬停图片时显示大图预览及文件名
- **文件大小与时间**：列表模式显示文件大小和修改时间
- **状态持久化**：记住上次盘符、文件夹、视图模式和排序方式

## 系统要求

- 思源笔记 v3.0.0+（桌面版）
- Windows 桌面环境
- 可选挂载工具将网盘挂载为本地盘

## 安装方法

1. 从 GitHub 下载最新版本的 ZIP 安装包
2. 思源笔记中：设置 → 集市 → 下载 → 导入
3. 选择 ZIP 文件并安装
4. 在插件列表中启用插件

## 使用教程

### 打开文件浏览器

1. 安装后，右侧 Dock 面板会出现一个**文件夹**图标
2. 点击图标打开文件浏览器面板
3. 面板会显示上次访问的位置（或默认盘符根目录）

### 浏览文件

- **单击文件夹**进入该目录
- **单击文件**选中（高亮显示）
- **双击文件**插入到当前笔记
- 点击顶部的**面包屑导航**返回上级目录
- 点击面包屑中的**首页图标（🏠）**返回盘符根目录

### 切换盘符

- 使用左上角的**盘符下拉框**切换不同驱动器（C:，D: 等）
- 插件会自动记住你上次选择的盘符

### 使用收藏夹

1. **右键点击**任意文件夹 → 选择 **"添加收藏"**
2. 收藏的文件夹会作为快捷标签显示在顶部
3. 点击收藏标签直接跳转到该文件夹
4. 右键点击收藏标签 → 选择 **"取消收藏"** 可删除

### 搜索文件

- **实时搜索**：在搜索框中输入文字，实时过滤当前目录的文件
- **深度搜索**：按 **回车键** 递归搜索所有子目录（默认最多五层）
- 深度搜索时会出现 **"返回"** 按钮，点击可回到普通浏览模式

### 排序文件

- 点击面包屑右侧的**排序按钮**（如 "↑ 名称"）
- 可选择：**按名称** / **按大小** / **按修改时间**
- 支持切换**升序 / 降序**
- 排序偏好会自动保存

### 切换视图

- 点击右上角的**视图切换按钮**（☰ / ⊞）切换：
  - **列表视图**：紧凑列表，显示文件名、大小和修改时间
  - **图标视图**：缩略图网格，支持图片预览
- 视图偏好会自动保存

### 图片预览

- 在**图标视图**下，鼠标悬停在图片文件上可显示大图预览
- 预览图显示在鼠标右侧
- 图片下方会显示**完整文件名**

### 插入文件到笔记

1. 找到要插入的文件
2. **双击**该文件（或右键 → "打开"）
3. 文件会自动：
   - 复制到思源工作区的 `data/assets/` 目录
   - 在当前编辑器光标位置插入
4. 图片文件：以 `![文件名](assets/文件名)` 形式插入
5. 其他文件：以 `[文件名](assets/文件名)` 链接形式插入

## 常见问题

### "无法访问目录"

- 确认驱动器已挂载且可访问
- 检查驱动器盘符是否正确

### "无法获取工作区路径"

- 确保使用的是思源笔记桌面版
- 插件需要访问本地文件系统权限

### 文件未插入

- 点击文件前确保编辑器已聚焦
- 如果自动插入失败，Markdown 链接会复制到剪贴板，直接 Ctrl+V 粘贴即可
