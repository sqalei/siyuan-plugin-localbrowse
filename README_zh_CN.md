## 前言

思源笔记很好用，但本地文件（视频、图片、文档、压缩包等）要么全部导入增加体积，要么每次手动找文件、手写链接，操作繁琐。**LocalBrowse** 把本地文件浏览器嵌入思源笔记的 Dock 面板，不用离开思源就能浏览、搜索、插入本地文件。【*插入链接后，难免要整理本地的文件，比如说挪动文件，这个时候插入笔记的文件链接就失效了*】，本插件的核心是：本地文件挪动位置，支持失效链接自动修复，并且支持跨平台，跨设备同步，所有数据均保存在本地，无离线，不笔记。

---

## 插件简介

**LocalBrowse**（本地文件浏览器）是一个思源笔记桌面端插件，在右侧 Dock 面板中提供本地文件浏览器，支持浏览、搜索、收藏、一键插入文件链接，以及失效链接自动修复和跨端同步文件夹功能。

- **适用平台**：Windows / macOS / Linux 桌面版思源笔记（v3.0.0+）
- **开源协议**：GPL-3.0
- **GitHub 仓库**：https://github.com/sqalei/siyuan-plugin-localbrowse

## 快速上手

### 1. 打开文件浏览器

安装启用后，右侧 Dock 面板出现 📂 图标，点击打开。

### 2. 浏览文件

- 左上角下拉框选择存储位置（Windows 盘符 / macOS 卷 / Linux 挂载点）
- 单击文件夹进入，点击面包屑导航返回上级
- 按 **Backspace** 键快速返回上级

### 3. 配置跨端同步文件夹（如果你有跨设备使用的习惯，推荐使用这个）

右键跨端同步文件夹按钮，弹出配置窗口，配置同步文件夹，如A 电脑 `D:\BaiduSyncdisk\LocalBrowseSync`，B 电脑 `E:\BaiduSyncdisk\LocalBrowseSync。

说明：LocalBrowseSync是固定的，选择在的文件夹如百度网盘的同步文件夹，点击保存会自动创建LocalBrowseSync，所有端设置的同步文件夹必须是LocalBrowseSync。

### 4. 插入文件链接

- **双击文件** → 插入本地文件链接（支持整理文件，如挪动文件位置，自动关联新路径）
- **右键文件夹** → 插入文件夹链接（📂 图标）

### 5. 收藏常用文件夹

右键点击文件夹 → "添加收藏"，以后点击顶部收藏标签一键跳转。

### 6. 失效链接自动修复

切换文档时插件自动检测链接，指示灯显示状态：

- 🟢 绿灯 = 所有链接正常
- 🟡 黄灯 = 有多候选，点击指示灯手动选择
- 🔴 红灯 = 有链接无法修复

## 功能详解

### 📁 浏览本地文件系统

自动检测所有可用存储，通过左上角下拉框快速切换。支持浏览本地磁盘、网盘挂载盘、同步盘等。

- 面包屑导航：点击任意层级快速返回
- Backspace 快捷键：返回上级目录
- 底部状态栏：显示当前目录文件数量和总大小

### ✨ 插入文件/文件夹链接

**双击文件**插入链接，不同文件类型的插入效果：


| 文件类型                                    | 插入格式                    | 效果                       |
| ------------------------------------------- | --------------------------- | -------------------------- |
| 图片（jpg/png/gif/webp/bmp/svg 等）         | `![文件名](file:///路径)`   | 思源内联显示图片           |
| 视频（mp4/webm/ogg/mov/mkv/flv/avi/wmv 等） | `[🎬 文件名](file:///路径)` | 带视频图标的可点击链接     |
| 其他文件（PDF/Word/Excel/压缩包等）         | `[📄 文件名](file:///路径)` | 带文件类型图标的可点击链接 |

**右键文件夹**插入文件夹链接：`[📂 文件夹名](file:///路径)`

**右键菜单**提供更多选项：


| 菜单项             | 说明                              | 跨设备可用                                  |
| ------------------ | --------------------------------- | ------------------------------------------- |
| 插入本地文件       | 复制文件到思源`assets` 目录后插入 | ✅ 任意设备可访问                           |
| 插入本地链接       | 插入`file:///` 本地绝对路径链接   | ⚠️ 仅本机（使用跨端同步文件夹，可以跨端） |
| 打开文件/文件夹    | 用系统默认程序打开                | —                                          |
| 在文件管理器中显示 | 打开文件/文件夹所在位置           | —                                          |
| 复制路径           | 复制完整路径到剪贴板              | —                                          |

**如何选择插入方式？**


| 场景                           | 推荐方式                            |
| ------------------------------ | ----------------------------------- |
| 文件在同步盘中，多台电脑都要用 | 双击插入 + 配置跨端同步文件夹       |
| 文件只在一台电脑使用           | 双击插入                            |
| 需要在所有设备（含手机）访问   | 右键 → 插入本地文件（存入 assets） |

### 🔍 搜索文件

- **实时过滤**：在搜索框输入关键词，即时过滤当前目录（支持多关键词空格分隔 AND 匹配）
- **深度搜索**：按 **Enter** 键或点击 🔍 按钮，递归搜索所有子目录，实时显示进度
- **取消搜索**：点击搜索框 × 或清空搜索框

### ⭐ 收藏夹

- **添加收藏**：右键文件夹 → "添加收藏"
- **取消收藏**：右键已收藏文件夹 → "取消收藏"
- **调整顺序**：拖拽收藏标签
- **快速跳转**：点击收藏标签直接跳转

### 📊 排序

点击工具栏 "⇅ 名称" 按钮，选择按 **名称/大小/修改时间** 排序，再次点击切换升降序。排序偏好自动保存。

### 🖼️ 视图切换

点击工具栏 ☰ / ⊞ 按钮切换：

- **列表视图**：紧凑排列，显示文件名、大小和修改时间
- **图标视图**：缩略图网格，图片悬停显示大图预览

偏好自动保存。

### 🔗 失效链接修复

插件自动检测当前文档中的 `file:///` 本地链接状态，工具栏指示灯实时反馈：


| 指示灯 | 状态 | 含义                                |
| ------ | ---- | ----------------------------------- |
| ⚪     | 白灯 | 当前文档没有本地文件链接            |
| ⏳     | 转圈 | 正在后台检测并修复...               |
| 🟢     | 绿灯 | 所有本地链接均有效 ✅               |
| 🟡     | 黄灯 | 有重名文件需要手动选择候选 ⚠️     |
| 🔴     | 红灯 | 文件已删除或重命名，无法自动修复 🔗 |

**自动修复（无感）**：打开文档时，插件自动在后台扫描并修复失效链接——搜到唯一匹配文件直接替换，无需操作。

**手动修复（黄灯/红灯时）**：

1. 点击工具栏的 🟡 或 🔴 指示灯
2. 弹出修复对话框，显示每个失效链接的修复状态
3. 多候选结果点击选择正确文件
4. 点击"应用修复"

---

### 🔄 跨端同步文件夹

使用同步盘（百度网盘、坚果云、iCloud Drive、OneDrive 等）在多台电脑间同步文件时，同一文件在不同电脑上的路径不同。配置跨端同步文件夹后，插件自动修复因路径不同导致的链接失效。

**支持的场景**：

- **跨平台**：Windows ↔ macOS ↔ Linux
- **同平台跨设备**：如两台 Windows 电脑盘符不同（如 `D:\` ↔ `E:\`）

#### 配置步骤

**每台电脑各做一次**：

1. **右键点击**工具栏的 🔄 按钮，打开设置面板
2. 面板标题显示当前平台标签（🪟 Windows / 🍎 macOS / 🐧 Linux）
3. 点击 📂 浏览按钮，选择网盘同步目录的**父文件夹**
   - 插件会自动创建 `LocalBrowseSync` 子文件夹，同步盘会自动同步该文件夹
4. 点击**保存**
5. 配置自动通过思源云同步到其他设备

**示例**：使用百度网盘同步，三台设备的配置：


| 设备       | 平台    | 选择的父文件夹                | 实际同步文件夹路径                            |
| ---------- | ------- | ----------------------------- | --------------------------------------------- |
| 公司台式机 | Windows | `D:\BaiduSyncdisk`            | `D:\BaiduSyncdisk\LocalBrowseSync`            |
| 家里笔记本 | Windows | `E:\BaiduSyncdisk`            | `E:\BaiduSyncdisk\LocalBrowseSync`            |
| MacBook    | macOS   | `/Users/sqalei/BaiduSyncdisk` | `/Users/sqalei/BaiduSyncdisk/LocalBrowseSync` |

**配置后效果**：

- 🔄 按钮显示为 **🔄 LocalBrowseSync**（绿色，表示已配置）
- 点击 🔄 按钮直接打开同步文件夹
- 右键 🔄 按钮可修改或清除配置

#### 跨端修复效果

在 A 电脑插入同步文件夹内的文件链接后，在 B 电脑打开同一篇笔记，插件自动将路径修复为 B 电脑的正确路径，无需手动操作。

同步文件夹内链接的修复流程：

1. 替换路径前缀 → 文件存在 → **直接修复** ✅
2. 替换路径前缀 → 文件不存在 → 在同步文件夹内**深度搜索** → 找到则修复
3. 搜索后仍找不到 → 宣告失败，不再全盘搜索

> 💡 非同步文件夹内的链接不受跨端修复影响：当前平台格式的链接走 R1→R2→R3 全盘搜索，其他平台格式的链接忽略（不修复）。

## 常见问题

**Q：提示"无法访问目录"？**
A：确认存储路径已正确挂载且可访问。网盘挂载工具需确保挂载服务正在运行。

**Q：文件没有插入到笔记中？**
A：确保双击文件前编辑器已聚焦（点击一下编辑区域）。插入失败时链接会自动复制到剪贴板，Ctrl+V 粘贴即可。

**Q：插入的链接在其他电脑上打不开？**
A：双击插入的是 `file:///` 本地链接，仅当前电脑有效。跨设备使用方案：

- **方案一**：右键 → "插入本地文件"，文件存入思源 `assets` 目录，同步后任意设备可访问
- **方案二**：文件在同步盘中，配置跨端同步文件夹后自动修复

**Q：支持 macOS / Linux 吗？**
A：✅ 全面支持三平台。macOS 自动检测 `/Volumes/` 挂载卷，Linux 自动检测 `/mnt/` 和 `/media/` 挂载点。

**Q：两台 Windows 电脑盘符不同能用吗？**
A：✅ 完全支持！但需要使用跨端同步文件夹功能，配置同步文件夹，如A 电脑 `D:\BaiduSyncdisk\LocalBrowseSync`，B 电脑 `E:\BaiduSyncdisk\LocalBrowseSync`，插件自动做盘符前缀替换。

**Q：跨端同步文件夹的名称必须一致吗？**
A：插件自动统一为 `LocalBrowseSync`，你只需选择父文件夹，无需担心名称不一致。但**父文件夹名称**（如 `BaiduSyncdisk`）在各设备上必须一致。

**Q：可以配置多组同步文件夹吗？**
A：目前只支持一组。多个同步盘建议放在同一个父文件夹下。

**Q：失效链接修复找不到文件？**
A：确保文件存在于可访问的存储上。网盘挂载盘需确认已正确挂载。R3 全盘搜索会覆盖所有存储（含挂载卷）。
